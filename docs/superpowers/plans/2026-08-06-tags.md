# Notebook Tags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Notebooks carry tags the agent proposes and you approve, and the overview's filter strip narrows by them — each tag cycling neutral → include → exclude.

**Architecture:** Tags live on the space's `:value` as `[{:tag :by :ts}]`, set by one reversible event through a `space?`-guarded endpoint. A second endpoint asks the agent for a proposal through the existing jobs layer and **writes nothing**. On the frontend the strip composes with the LEAP filter built earlier today: one dimming path, one crumb, one predicate — a notebook is lit when it satisfies the LEAP filter *and* the tag predicate.

**Tech Stack:** Clojure 1.12 (`src/loci/server.clj`, `src/loci/agent.clj`), vanilla JS/CSS (`resources/public/index.html`), cognitect test-runner, node --test + playwright-core.

**Spec:** `docs/superpowers/specs/2026-08-06-tags-and-overview-design.md` §2 (§1 is already built and merged).

**Facts the implementer needs:**
- **The filter machinery already exists and must be extended, not duplicated.** `resources/public/index.html` has `overviewFilter` (`{q, ids:Set}` or null, ~line 1121), `notebooksMatching(entries)`, `applyOverviewFilter()` (dims panels + renders `#crumbFilter` in the crumb), `clearOverviewFilter()`, `scrollToFirstMatch()`. `layout()` calls `applyOverviewFilter()` last so the dimming survives resize.
- **`.panel.dim` needs `!important`.** `layout()`'s `place()` writes `p.style.opacity='1'` inline on every panel, and an inline style beats a stylesheet rule. A dim rule without `!important` is a **silent no-op** — this shipped once today: classes correct, crumb correct, screen unchanged. Tests must assert **computed opacity**, never class membership.
- The crumb (`#crumb`) toggles focus/overview on click, so **anything clickable inside it must `stopPropagation()`**.
- Writes to a notebook follow `notebook-op!` (`server.clj:226`): look up the object, refuse a non-space with `{:error "not a notebook: <id>"}`, commit, return `{:state (state-payload st) …}`.
- Long agent calls go through `start-job!` (`server.clj:786`) which returns a job id; the shell polls `GET /api/job?id=`. Never hold a request open for an LLM call.
- Agent functions live in `src/loci/agent.clj` and follow one shape: build a `sys` string, call `(chat msgs :json? true)`, `json/read-str … :key-fn keyword`, pull one key out. `propose-subtopics` (`:192`) is the closest model.
- `state-payload` (`server.clj:73`) builds each space map with `cond->`; `:tags` goes there.
- **Definition order is load-bearing.** `server.clj` is one long namespace with no
  declares: `space?` is at `:293`, `obj-digest` at `:569`, `start-job!` at `:786`. Anything
  using them must be defined below them. This has caused a forward-reference failure in
  this file before.
- The shell's globals are **not on `window`** — `let STATE`, `let overviewFilter` are lexical globals. `page.evaluate(() => overview())` works; `window.STATE` is always `undefined`. Guard `waitForFunction` with `typeof x !== 'undefined'`.
- Baseline: `clojure -M:test` **136 tests / 615 assertions**; `npm run test:browser` **20 tests**. Both must stay green.
- **Never point anything at `data/`** — the user's real substrate, md5 `e7a6eecdff7bb44ad6b959bb1a7fb7c6`. A server runs on :7777 against it; leave it alone. The harness boots its own with a throwaway `LOCI_DATA`.

;; ---- tags: subject, the one thing the substrate cannot compute ----
;; Structure is derived (spawned-by, shares, lineage) and never maintained.
;; Subject cannot be, so it is asserted — by the agent or by you, and :by
;; records which, the way the memory pane cites its sources.
(defn- clean-tags
  "Trimmed, lower-cased, de-duplicated, blanks dropped, order preserved."
  [tags]
  (->> tags
       (keep (fn [t] (let [s (str/lower-case (str/trim (str (:tag t))))]
                       (when-not (str/blank? s)
                         {:tag s :by (if (= "agent" (:by t)) "agent" "you")
                          :ts (or (:ts t) (System/currentTimeMillis))}))))
       (reduce (fn [acc t] (if (some #(= (:tag %) (:tag t)) acc) acc (conj acc t))) [])))

(defn set-tags!
  "Replace a notebook's tags — one reversible event, or none when nothing changed."
  [st space tags]
  (let [o (sub/object st space)]
    (if-not (= :space (:kind o))
      {:error (str "not a notebook: " space)}
      (let [now  (clean-tags tags)
            was  (get-in o [:value :tags])]
        (when (not= (mapv :tag was) (mapv :tag now))
          (sub/commit! st {:op :assoc :id space :path [:value :tags] :value now}))
        {:state (state-payload st) :tags now}))))
```

(defn suggest-tags!
  "Ask the agent for tags. Writes NOTHING — a proposal you ignore leaves no
   trace at all, which is a stronger promise than reversibility."
  [st space]
  (let [o (sub/object st space)]
    (if-not (= :space (:kind o))
      {:error (str "not a notebook: " space)}
      (try
        (let [digest (->> (nb/cells-of o) (keep #(sub/object st (:ref %)))
                          (map obj-digest) (str/join "\n"))]
          {:tags (vec (take 3 (agent/propose-tags (:title o)
                                                  (get-in o [:value :intent]) digest)))})
        (catch Exception e {:error (.getMessage e)})))))

(defn inherit-tags
  "A deep-dive child is created ABOUT its parent's subject, so it starts with
   the parent's tags — as inferences, because you asserted them of the parent,
   not of the child."
  [st space]
  (mapv #(assoc % :by "agent" :ts (System/currentTimeMillis))
        (get-in (sub/object st space) [:value :tags])))

// ---------------- tags narrow the same set LEAP's filter narrows ----------------
// One dimming path, one crumb, one predicate. A second parallel filter with its
// own rules would be the mode this design has avoided throughout.
let tagState={};                  // {tag: 'in' | 'out'} — absent means neutral

function allTags(){
  const seen=new Map();
  STATE.spaces.forEach(sp=>(sp.tags||[]).forEach(t=>seen.set(t.tag,(seen.get(t.tag)||0)+1)));
  return [...seen.entries()].sort((a,b)=>b[1]-a[1]||a[0].localeCompare(b[0]));
}

// include if it carries any included tag (or none are included); exclude wins,
// because "semiconductors except the geopolitics" is the question people ask
function passesTags(sp){
  const on=Object.entries(tagState);
  if(!on.length) return true;
  const mine=new Set((sp.tags||[]).map(t=>t.tag));
  const inc=on.filter(([,v])=>v==='in').map(([t])=>t);
  const exc=on.filter(([,v])=>v==='out').map(([t])=>t);
  if(exc.some(t=>mine.has(t))) return false;
  return !inc.length || inc.some(t=>mine.has(t));
}

function cycleTag(tag){
  tagState[tag] = tagState[tag]==='in' ? 'out' : tagState[tag]==='out' ? undefined : 'in';
  if(!tagState[tag]) delete tagState[tag];
  renderTagStrip(); applyOverviewFilter();
}
function clearTags(){ tagState={}; renderTagStrip(); }
```

// Tags narrow the overview: include, exclude, or neither — and they compose
// with LEAP's filter rather than being a second mechanism.
import { test, before, after } from 'node:test';
import assert from 'node:assert/strict';
import { startServer, launchBrowser, withPage, bootedShell } from './harness.mjs';

let server, browser;
before(async () => { server = await startServer(); browser = await launchBrowser(); });
after(async () => { await browser?.close(); await server?.stop(); });

// panels transition opacity, so settle before measuring — and measure COMPUTED
// opacity, never class membership: a class-counting assertion passed through an
// entire shipped no-op on 2026-08-06 (layout() writes inline opacity, which
// beats a stylesheet rule).
const settle = async (page) => {
  await page.evaluate(() => new Promise(res => {
    let last = '', same = 0, frames = 0;
    const tick = () => {
      const now = [...document.querySelectorAll('.panel')]
        .map(p => getComputedStyle(p).opacity).join(',');
      same = now === last ? same + 1 : 0; last = now;
      if (same >= 3 || ++frames > 400) return res();
      requestAnimationFrame(tick);
    };
    requestAnimationFrame(tick);
  }));
};

const opacities = (page) => page.evaluate(() => {
  const out = {};
  STATE.spaces.forEach((s, k) => { out[s.id] = +getComputedStyle(panels[k]).opacity; });
  return out;
});

const inOverview = async (page) => {
  await page.evaluate(() => overview());
  await page.waitForFunction(() => document.getElementById('world').classList.contains('cards'));

test('the strip shows every tag in the corpus, most common first', async () => {

    await page.waitForSelector('#tagstrip .tagchip');
    const chips = await page.$$eval('#tagstrip .tagchip', els => els.map(e => e.dataset.tag));
    assert.deepEqual(chips.slice(0, 1), ['company'], 'two notebooks carry it, so it leads');
    assert.ok(chips.includes('astronomy') && chips.includes('pipeline'));
  });
});

test('including a tag lights its notebooks and dims the rest, in pixels', async () => {
  await withPage(browser, 'tag-include-dims', async (page) => {
    await bootedShell(page, server.url);
    await inOverview(page);
    await page.click('#tagstrip .tagchip[data-tag="company"]');
    await settle(page);
